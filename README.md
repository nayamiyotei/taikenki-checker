# 体験記チェッカー（一次チェック専用・単独版）

アンケート・本文の校正と、タイトル案づくりだけを行うツールです。画像編集は含まれません。

## ファイル構成
```
checker/
├── index.html
├── css/style.css          ← 桜デザイン（ライト／夜桜ダーク。「テーマ」ボタンで切替）
└── js/
    ├── rules.js           ← 【変更なし】ルール定義。ルールの追加・変更はここだけ
    ├── rule-engine.js     ← 【変更なし】決定的チェック
    ├── gemini-client.js   ← 【変更なし】Gemini通信
    └── app.js             ← 【新規】画面操作・プロンプト・結果表示
```

## 以前のチェッカーとの違い
- 「画像編集」タブと image-editor.js を削除（単独ツールにした）
- デザインを桜のテーマに変更（index.html と css/style.css のみ。js は変更なし）。タイトルは「合格体験記　一次チェックツール」
- タイトル・タブ・テーマ切替（月／太陽アイコン）は、画面上部に固定表示
- タブは「アンケート／本文校正／タイトル案」の3つ（旧：本文タブ内のラジオ切替を独立）
- 各指摘に「採用／不採用／要相談」の判断ボタンと、集計・コピー機能を追加
- 「ルールのみ（送信なし）」ボタンを追加（AIを使わず、どこにも送信しない）
- AIチェックの前に「伏せ字にしました」のチェックが必要（js/app.js 冒頭の CONFIG.REQUIRE_MASK_CONFIRM を false にすると無効）
- 本文校正で、指摘箇所をプレビュー上にハイライト

## 注意
- app.js は、元の app.js を見ずに新しく書き直したものです。プロンプトの文面や、アンケートの分割方法（「掲載する」を区切りにする）は、元の動作を推定して作っています。差があれば app.js の buildSurveyPrompt / buildProofPrompt / buildTitlePrompt / parseSurvey を調整してください。
- 文字は Google Fonts（Shippori Mincho B1 / Zen Kaku Gothic New）を読み込みます。オフラインでは、システムの明朝・ゴシックで表示されます。

## 公開方法
画像編集ツールのREADMEと同じです。Cloudflare Pages では、functions/_middleware.js（ID・パスワード認証）をリポジトリのルートに置いたまま、このフォルダの中身を公開してください。

## 追加機能（2026-11 版）

- **00 まるごと**：管理画面の表示をそのまま貼り付け → 見出し行（「アンケート結果」「本文」「タイトル案」）を目印に自動で3タブへ振り分け。「③つをまとめてチェック」「ルールのみ（送信なし）」。結果は各タブで見られ、00 の下に「管理画面へ入力（コピー）」欄が出ます。
  ※ 振り分けは見出し行の文字一致で行っています。実際の管理画面のコピー結果と形が違うときは `js/app.js` の `HEADS`（見出しの正規表現）を直してください。
- **承認・却下**：「採用」を押すと「修正後の本文」にその場で反映（削除＝取り消し線、追加＝緑）。「すべて採用」「未判断を不採用に」「元に戻す」「本文をコピー」。
- **文字数**：自動カウントのみ（空白・改行を除く文字数／段落数）。**超過の判定はしません**。
- **管理画面へ入力（コピー）**：アンケート各項目・本文（修正後）・タイトルをワンクリックでコピー（コピー済み表示）。
- **利用の記録**：設定の「あなたの名前」を端末に保存し、チェックを実行するたびに「名前・日時・ツール名・機能・件数」だけをGoogleスプレッドシートに記録します（本文・画像は送りません）。

### 利用の記録の設定（Googleスプレッドシート）
1. 新しいスプレッドシートを作る → 拡張機能 → Apps Script
2. 次のコードを貼り付けて保存
```js
function doPost(e) {
  var d = JSON.parse(e.postData.contents);
  var sh = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  if (sh.getLastRow() === 0) sh.appendRow(["日時","名前","ツール","機能","件数"]);
  sh.appendRow([new Date(d.ts), d.name, d.tool, d.action, d.count]);
  return ContentService.createTextOutput("ok");
}
```
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／次のユーザーとして実行「自分」／アクセスできるユーザー「全員」→ デプロイ → 表示されたURLをコピー
4. `js/logger.js` の `LOG_URL` にそのURLを貼って、再デプロイ（空のままなら記録は無効）
※ 集計はスプレッドシートのピボットテーブルで「名前×日付×件数」を出せます。URLを知っている人は誰でも書き込めるので、URLは社外に出さないでください。
